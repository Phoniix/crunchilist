Privacy

Last updated: 27 October 2026

Kivori SekAI is a browser extension. It has no developer server and no analytics. The developer never receives your data unless you paste diagnostics into a GitHub issue.

Everything Kivori SekAI knows about you stays in your browser, except for the requests below, which go straight from your browser to the service named.

What stays on your device

  • Your list and progress: statuses, episodes watched, and shows you mark.
  • Settings: theme, playback, search, notification, badge, import and tracking preferences.
  • Catalog cache: titles and AniList details so pages load fast.
  • Continue watching activity: recent plays used to order Home.
  • Import checkpoints, matches, pending picks, import history and activity log: so catch-up and Help → Activity log work.
  • In-app notices: episode asks, sync/import previews, applied syncs, update reminders (bell drawer). They never leave the device by themselves.
  • Favorite character preference when that feature is used.
  • Sign-in tokens and API keys: AniList and MyAnimeList tokens, and any AI keys you add, in Chrome local extension storage (not synced). They are only sent to the service they belong to. AI keys are never included in backup files. A short-lived Crunchyroll session token may be kept in session storage while a Crunchyroll tab is open; it is cleared when you sign out of Crunchyroll or close the session.

Removing the extension deletes all of it.

Crunchyroll

On crunchyroll.com, Kivori SekAI reads the page you're on and uses your existing Crunchyroll session to load the catalog and, if you ask it to, your watch history. Daily sync re-reads about the last week of history (or since your last checkpoint if that's newer). A full Import is still how you backfill older history. It adds status badges and the "Back to Kivori SekAI" button. It does not read or store your Crunchyroll password, payment details or profile.

Other watch sites

Netflix, Prime Video, HIDIVE, Tubi and Hulu are only reached after you grant access. History, progress and as-you-watch tracking follow the options you turn on. Disconnecting a site (and confirming) forgets that site's local data on this device.

AniList, MyAnimeList and Kitsu

If you connect AniList, Kivori SekAI signs you in through AniList's own page and syncs your list and progress. It also looks up public show details (art, scores, studios, airing dates). Importing a public username only reads that public list. MyAnimeList and Kitsu connections, when you enable them, pull or push list data according to your tracker settings.

AI ranking

By default, AI ranking can use the model built into Chrome on your device. If you add a key for an AI provider (OpenAI, Google Gemini, Groq, OpenRouter, or a custom address you enter), searches you rank with AI send that provider your search text, the candidate titles with your status for each, and a short summary of the genres and tags you like. That request is covered by the provider's own privacy policy. Nothing is sent to a provider you haven't added.

GitHub

Sideload copies check GitHub for new Releases and may download release zips or public feed files (for example id-map / where-map) from the project repository. When you use Help → Send feedback, diagnostics and the activity log are copied on your device; if you paste them into a GitHub Issue, that text becomes visible on GitHub (and to the developer).

Trailers

Trailers use a privacy-enhanced embed and only load when a trailer is on screen. You can turn trailer previews off in Settings.

Backups and diagnostics

Backups you download include matches, settings (without AI keys), import history and the activity log when present — not sign-in tokens. Diagnostics and the activity export are plain-text summaries (versions, connections, recent outcomes) with no passwords or API keys.

Permissions

  • Storage: list, settings, catalogs, notices and logs on this device.
  • Tabs and navigation: opens episodes in your Crunchyroll tab, reuses it, and can fold extra Crunchyroll tabs into it.
  • Identity: AniList (and MAL when connected) sign-in windows.
  • Alarms / scripting: daily sync, tracking and site scripts you allow.
  • Network rules: lets trailers play inside the Kivori SekAI page.
  • Site access: Crunchyroll, AniList, connected watch sites, listed AI providers, trailer embeds, and GitHub for updates/feeds. Other sites only if you add a custom AI address and allow it.

Contact

Questions about privacy or the product: open a GitHub Issue, or use Settings → Help → Send feedback.
