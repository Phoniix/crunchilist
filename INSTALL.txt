Kivori SekAI — install (Windows)

1. Unzip this folder anywhere (Downloads is fine).

2. Double-click install.cmd
   It downloads the newest GitHub release into:
   %LOCALAPPDATA%\KivoriSekAI

3. Chrome opens chrome://extensions
   - Turn on Developer mode (top right) — leave it on
   - Click "Load unpacked"
   - Choose the KivoriSekAI folder above

4. Later updates
   Open Kivori SekAI → Settings → Update now
   Or double-click update.cmd in that same folder

Your list and settings live in Chrome, not in the folder, so they stay
when you update.

Releases: https://github.com/Phoniix/crunchilist/releases
